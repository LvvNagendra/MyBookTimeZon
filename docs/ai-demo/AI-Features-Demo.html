4. Enable live Gemini (STS)

  1. Open Run Configuration for MyBookTimeZonApplication.
  2. Add environment variables: 
    GEMINI_API_KEY=<your-key>
BEAUTY_COACH_LLM=GEMINI
GEMINI_MODEL=gemini-3.8-flash
  3. Restart the app (env must be on the javaw process, not only PowerShell).
  4. Call chat again — reply should no longer say “Offline coach” when quota allows.

5. Live demo script (5 minutes)

  1. Pitch: Java SaaS where Flash helps in the background of booking + beauty coaching.
  2. Open /coach — ask for oily-scalp / oval-face tips.

  4. Open /skin — facial context → coach tips.
